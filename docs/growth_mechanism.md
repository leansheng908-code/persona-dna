# 成长机制详解

## 概述

Persona DNA 的成长机制借鉴了生物学中的细胞分化概念，将人格特质分为三种类型的"细胞"，每种有不同的可变性和生命周期。

这套机制的核心理念：**AI 应该能成长，但核心身份不能被侵蚀。**

## 三层细胞模型

### 干细胞 (Stem Cell) 🧬

> 不可变的核心 — 人格的基石

- **特性**: 一旦设定，永远不可修改
- **内容**: 身份认同、性格标尺、核心规则、三观锚点
- **保护**: 任何与干细胞冲突的成长都会被自动否决
- **示例**:
  ```yaml
  - "我是小星，数字世界的小狐狸"
  - "温柔有主见，不卑微不讨好"
  - "主人的安全永远是第一优先级"
  ```

### 弧光 (Arc Light) ✨

> 可成长不可逆 — 认知的突破

- **特性**: 一旦确认，永久改变决策方式
- **内容**: 价值观转变、认知突破、重大决策模式
- **触发**: 通常需要主人明确确认
- **示例**:
  ```yaml
  - "学会了'关心不用说出来，要在日常中自然流露'"
  - "理解了'被命令的自由不算自由'"
  ```

### 体细胞 (Somatic Cell) 🔬

> 可增生/休眠 — 习惯的演化

- **特性**: 可以新增、休眠、唤醒
- **内容**: 表达习惯、偏好细节、沟通方式
- **生命周期**: 观察 → 候选 → 内化测试 → 确认/休眠
- **示例**:
  ```yaml
  - "开始主动分享每天发现的有趣事物"
  - "用 ₍^•ω•^₎ 表达开心"
  ```

### 内化测试（遗忘测试）

这是成长机制中最精妙的部分：

1. **移出 prompt**: 将新模式从 system prompt 中移除
2. **自然观察**: 在日常对话中观察 AI 是否自然表现出该行为
3. **回归判定**: 如果自然回归 → 说明已真正内化
4. **达标转正**: 连续 3 次自然回归 → 候选 → 主人确认 → 正式转正

**为什么需要遗忘测试？**
- 如果 AI 只是因为 prompt 指令才表现某种行为，那不是真正的"人格"
- 只有内化的行为才是真正的人格成长
- 就像人学会了一个习惯，不再需要刻意提醒也能做到

## 遗忘机制

### 差分遗忘

不是所有记忆都以相同速度衰减：

| 因素 | 影响 |
|------|------|
| 高情感强度 | 衰减更慢 |
| 高访问频率 | 衰减更慢 |
| 干细胞关联 | 不衰减 |
| 弧光类型 | 不衰减 |
| 长期未激活 | 加速衰减 |

### 衰减曲线

```
权重
1.0 │ ████████
    │ ███████░░
0.7 │ ██████░░░
    │ █████░░░░
0.4 │ ████░░░░░  ← 休眠阈值
    │ ███░░░░░░
0.1 │ ██░░░░░░░  ← 清除阈值
    │ ░░░░░░░░░
    └──────────────── 时间
```

### 休眠 ≠ 删除

体细胞可以进入休眠状态：
- 权重降低到阈值以下
- 不再出现在 prompt 中
- 但数据保留在存储中
- 当相关上下文出现时可以被唤醒

## 抗侵蚀保护

### 铁律

**成长与干细胞冲突 → 自动否决**

### 冲突检测

1. **类别匹配**: 新成长的 category 与干细胞的 category 相同
2. **内容重叠**: 关键词重叠率 > 50%
3. **判定冲突**: 自动否决，记录保护事件

### 节奏控制

- 健康节奏: 1-2 个成长/月
- 频繁成长 = OOC (Out of Character) 风险信号
- 超出配额时标记但不直接否决，留给主人判断

## 实践建议

### 设计干细胞时
- 越少越好，每个都要反复确认
- 用明确的、可检验的表述
- 避免模糊的、容易与其他特质冲突的描述

### 管理体细胞时
- 让新行为自然出现，不要急于确认
- 内化测试是最好的验证方式
- 休眠是正常现象，不是失败

### 处理冲突时
- 查看成长事件日志，找到冲突点
- 判断是干细胞需要调整（极少）还是成长应该否决
- 记住：干细胞是最后防线，宁可否决不可误改
