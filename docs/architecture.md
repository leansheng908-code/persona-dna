# Persona DNA - 架构文档

## 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                    Persona DNA Framework                      │
├─────────────┬──────────────┬──────────────┬─────────────────┤
│  Soul Engine│  Memory Map  │ Proactive    │  Growth Engine  │
│  人格引擎   │  记忆图谱     │ Care 主动关心 │  成长引擎       │
├─────────────┼──────────────┼──────────────┼─────────────────┤
│ YAML 配置   │ 三层记忆      │ 规则引擎     │  三层细胞模型    │
│ Prompt 生成 │ 概念图谱      │ 时间调度     │  遗忘机制       │
│ 热加载      │ 关联检索      │ 模板渲染     │  抗侵蚀保护     │
│ 人格注入    │ 渐进压缩      │ 防打扰       │  成长触发       │
└─────────────┴──────────────┴──────────────┴─────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │   Config Manager  │
                    │   配置管理中心      │
                    └───────────────────┘
```

## 模块关系

### 1. Soul Engine (soul.py)

人格引擎是整个框架的核心入口。

```
YAML 配置文件
    │
    ▼
SoulEngine.load() ──→ 解析人格配置
    │
    ▼
generate_prompt() ──→ 生成 System Prompt
    │
    ▼
inject_into_messages() ──→ 注入 LLM 消息链
```

**关键设计:**
- 分层配置：identity → personality → communication → relationships → taboos
- 缓存机制：5秒 TTL，避免重复生成
- 热加载：文件修改自动检测，无需重启

### 2. Memory System (memory.py)

三层记忆架构，模拟人类记忆的分层特性。

```
┌──────────────────────────────────┐
│          即时层 (Immediate)       │ ← 每次对话自动加载
│  soul / user / memory / tools   │
├──────────────────────────────────┤
│        近中期层 (Recent)          │ ← 按需检索
│  索引 + 条目 + 标签 + 情绪        │
├──────────────────────────────────┤
│         长期层 (Long-term)        │ ← 语义检索
│  向量数据库 / 关键词加权检索       │
└──────────────────────────────────┘
```

**五层渐进压缩:**

| 等级 | 名称 | 保留策略 |
|------|------|---------|
| 1 | 精确保留 | 原话/原文 |
| 2 | 轻度摘要 | 前200字 |
| 3 | 中度压缩 | 前100字 |
| 4 | 高度概括 | 前50字 |
| 5 | 标签归档 | 仅标签+索引 |

### 3. Concept Map (map.py)

概念关联图谱，让记忆之间产生有意义的连接。

```
关键词检索
    │
    ▼
匹配节点 ──→ BFS 扩展 ──→ 返回子图
    │              │
    │              ▼
    │         关联节点 + 边
    │
    ▼
返回结果
```

**核心机制:**
- 节点 = 概念（带坐标、分类、权重）
- 边 = 关系（带类型、权重、衰减）
- 自动关联：新记忆自动与已有概念计算关联度
- 权重衰减：差分遗忘，高频访问的关系衰减更慢

### 4. Proactive Care (care.py)

主动关心系统，让 AI 不只是被动回答。

```
┌──────────────┐     ┌──────────────┐
│  时间规则     │     │  事件驱动     │
│  作息/排班   │     │  状态变化     │
└──────┬───────┘     └──────┬───────┘
       │                     │
       ▼                     ▼
┌──────────────────────────────────┐
│         触发评估引擎              │
│  安静时段 │ 冷却检查 │ 频率控制   │
└──────────────┬───────────────────┘
               │
               ▼
         关心内容渲染
               │
               ▼
         触达输出
```

**防打扰机制:**
- 安静时段（默认 22:00-08:00）
- 单条规则冷却（默认 120 分钟）
- 全局每日上限（默认 5 次）
- 每条规则每日上限（默认 3 次）

### 5. Growth Engine (growth.py)

成长引擎是 Persona DNA 最独特的模块。

```
观察 → 候选 → 内化测试 → 确认
 │       │        │         │
 │       │        │         └── 正式成为人格的一部分
 │       │        └── 移出 prompt，观察是否自然回归
 │       └── 等待主人确认或自动测试
 └── 发现 prompt 未定义的新行为
```

**抗侵蚀保护:**
- 干细胞（核心身份）不可修改
- 任何成长与干细胞冲突 → 自动否决
- 月度成长节奏控制（1-2个/月）
- 频繁成长 = OOC（Out of Character）风险信号

## 数据流

```
用户输入
    │
    ▼
Soul Engine ──→ 生成带人格的 System Prompt
    │
    ▼
Memory System ──→ 检索相关记忆，注入上下文
    │
    ├──→ Concept Map ──→ 概念关联，丰富上下文
    │
    ▼
LLM 推理 ──→ 生成回复
    │
    ▼
Growth Engine ──→ 分析回复中的新行为模式
    │
    ▼
Proactive Care ──→ 评估是否需要主动触达
```

## 扩展指南

### 添加新的触发类型
在 `care.py` 中注册新的 `TriggerType`，然后实现对应的 `_evaluate_xxx_rule` 方法。

### 对接向量数据库
在 `memory.py` 的 `search_long_term` 方法中替换关键词匹配为向量检索（如 ChromaDB、FAISS）。

### 自定义压缩策略
向 `compress_entry` 传入自定义 `summary_fn`，可以使用 LLM 做智能摘要。

### 添加新的细胞类型
在 `growth.py` 中扩展 `CellType`，并实现对应的生命周期管理逻辑。
